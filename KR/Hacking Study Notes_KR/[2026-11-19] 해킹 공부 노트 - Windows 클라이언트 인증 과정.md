Windows에서 사용자가 로그인할 때는 한 프로그램이 모든 작업을 처리하지 않는다   
로그인 정보를 입력받는 구성 요소, 인증을 처리하는 구성 요소, 계정 정보를 저장하는 위치가 각각 다르다  
이 글에선 로그인 화면에서 시작한 요청이 어떻게 인증되는지, 그리고 SAM·LSASS·NTDS.dit·Credential Manager가 각각 무엇인지 정리하도록 하겠다

## 1. 로그인 정보를 입력받는 단계 
사용자가 windows로 로그인 화면을 열면 Winlogon(로그인과 화면 잠금·해제 절차를 관리하는 시스템 프로세스)이 대화형 로그인 절차를 관리한다.  
절차는 다음과 같이 진행된다:
```bash 
1. winlogon이 LogonUI를 실행
2. LogonUI이 로그인 화면을 표시
3. Credential Provider이 비밀번호·PIN·스마트 카드 등 선택한 방식에 맞춰 로그인 정보를 수집
```
참고로 Credential Provider는 입력한 비밀번호가 맞는지 직접 판단하지 않고 수집한 정보를 인증에 사용할 수 있는 형태로 준비해 다음 단계로 전달한다

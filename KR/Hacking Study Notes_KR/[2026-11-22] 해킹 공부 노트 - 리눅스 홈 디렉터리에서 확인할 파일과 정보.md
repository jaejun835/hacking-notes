리눅스 사용자 홈 디렉터리에는 셸 사용 기록과 설정, 접속 정보, 브라우저 데이터, 프로그램별 파일, 문서 등이 저장된다.  
SSH로 접속하거나 FTP·SMB에서 사용자 디렉터리를 발견했을 때 다음과 같은 목록들을 흔히 볼 수 있다.

목록들:
```bash
.bash_history
.bash_logout
.bashrc
.cache
.config
.local
.mozilla
.profile
.viminfo
Desktop
Documents
Downloads
Music
Pictures
Public
Templates
Videos
```

앞에 점(.)이 붙은 항목은 일반적인 목록 출력에서 보이지 않는 숨김 항목이다.   
하지만 숨김 여부는 파일의 중요도와 관계없고 Documents나 Downloads에 있는 일반 파일이 더 중요한 단서가 될 수도 있다. 

## 셸 기록과 설정 파일
| 파일 | 저장하는 내용 | 확인할 만한 정보
| --- | --- | --- |
| `.bash_history` | Bash에서 입력한 명령 기록 |	실행한 스크립트, 접속 주소, 작업한 파일 경로 |
| `.bashrc` |	대화형 Bash 셸을 시작할 때 읽는 설정 | 별칭, 사용자 정의 함수, 환경 변수, 실행 스크립트 |
| `.profile` | 로그인 셸을 시작할 때 읽을 수 있는 설정 | 사용자별 경로와 로그인 시 실행하는 작업 |
| `.bash_logout` | Bash 로그인 셸이 종료될 때 실행하는 명령 | 종료 시 실행되는 사용자 지정 작업 |
